# Contributing to LittleSocrates

We welcome contributions from **teachers, child psychologists, pediatric learning specialists, parents, and AI prompt engineers**!

---

## 🌟 Areas We Need Help With

1. **Subject Domain Scaffolds:**
   - Crafting age-appropriate metaphors for middle-school algebra, chemistry, foreign languages, and biology.
2. **Pedagogical Stress-Testing:**
   - Testing bypass and "jailbreak" prompts children use to make the AI spit out direct answers.
3. **Multi-lingual Adaptation:**
   - Translating and culturally adapting the scaffolding framework into Spanish, Hindi, French, Mandarin, Bengali, Arabic, etc.
4. **Platform Integrations:**
   - Adding native wrappers for Discord bots, WhatsApp tutors, Slack education bots, and local LLM runners (LM Studio, Jan, Ollama).

---

## 📝 Guidelines

- **Focus on the Child:** Always prioritize psychological safety, growth mindset, and cognitive load theory.
- **Never Complicate:** Explanations should always stay simple enough for a 9-year-old to understand immediately.
- **Formatting:** Keep paragraphs short, punchy, and emoji-friendly.

---

## 🚀 How to Submit a Pull Request

1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/new-subject-scaffold`.
3. Commit your changes: `git commit -m 'feat: Add middle school chemistry scaffolding'`.
4. Push to the branch: `git push origin feature/new-subject-scaffold`.
5. Open a Pull Request with a clear description and sample transcripts.
